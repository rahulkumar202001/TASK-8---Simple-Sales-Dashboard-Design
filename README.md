Superstore Sales Dashboard - Power BI Project

Objective
To create an interactive Power BI dashboard that visualizes sales performance by Region, Product Category, and Month-Year, using the Superstore Sales dataset.

Dataset Used
- Name: Sample - Superstore Sales
- Format: Excel (.xls)
- Columns Used: Order Date, Region, Category, Sales, Profit

Tools Used
- Power BI (Data Visualization)

Dashboard Features
- Line Chart: Monthly Sales Trend (Order Date converted to Month-Year format)
- Bar Chart: Sales by Region
- Donut Chart: Sales by Category
- Slicer: Filter by Region or Category
- Conditional formatting used to highlight top performers

Key Insights
1. West region had the highest total sales, especially strong in Q4.
2. Technology category led all others in sales consistently.
3. Central region recorded the lowest performance in both sales and profit.
4. December saw the highest spike in sales across most regions and categories.


Outcome
This project demonstrates how to:
- Import and transform data in Power BI
- Build a clean, interactive dashboard
- Derive actionable business insights from sales data
